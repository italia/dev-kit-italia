Toolbar

Menu di navigazione a icone che può contenere link, pulsanti e dropdown.

Toolbar grande

Versione predefinita con icone grandi e label visibili.

Toolbar media

Nella versione media (size="md") le label vengono nascoste visivamente.

Toolbar piccola

La versione piccola (size="sm") nasconde anch'essa le label visivamente.

Toolbar con divisori

È possibile aggiungere divisori per raggruppare logicamente gli elementi.

Toolbar con badge

I badge indicano contenuti non letti o notifiche. Usa label-extended per una descrizione accessibile agli screen reader.

Toolbar con dropdown

Aggiungendo l'attributo dropdown a it-toolbar-item si ottiene un elemento con menu a tendina. Le voci del menu vanno inserite nello slot items.
