# Number input

<description>Campo di inserimento di un valore numerico, con pulsanti per incrementarlo o decrementarlo.</description>

## Cosa fa
Il componente Number input (`it-input` con `type="number"`) permette all’utente di inserire un numero specifico digitandolo manualmente o selezionandolo tramite appositi pulsanti che incremenatano o diminuiscono un valore numerico di partenza.

Aiuta a prevenire errori e facilita l'inserimento dei dati, per questo è particolarmente utile quando bisogna indicare quantità, codici numerici e intervalli di valori con precisione.

[Approfondisci come e quando usare il componente Number input](https://designers.italia.it/design-system/componenti/number-input/)

## Indicazioni generali

Il componente Number input è una variante del componente `<it-input>` con l'attributo `type=` impostato su `number` (`type="number"`).

Fai riferimento alla [documentazione del componente Input](?path=/docs/componenti-form-input--documentazione) per:

- la **validazione** e la **gestione degli errori**;
- la **gestione degli eventi**;
- i **metodi e le proprietà** accessibili tramite JavaScript;
- il **supporto all’internazionalizzazione (i18n)**.

## Accessibilità

Tutti gli attributi `it-aria-*` passati a `<it-input>` vengono applicati all'input generato.
