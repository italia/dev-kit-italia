# Upload

<description>Campo per la selezione e il caricamento di file.</description>

## Cosa fa

I componenti Upload (`<it-upload>`, `<it-upload-avatar>`, `<it-upload-drag-drop>`) permettono di caricare documenti, immagini e foto profilo tramite selezione o drag & drop, mostrando l'anteprima delle immagini e gli stati di avanzamento.

[Approfondisci come e quando usare il componente Upload](https://designers.italia.it/design-system/componenti/upload/)

## Indicazioni generali

Scegli tra 3 componenti distinti in base alle esigenze di caricamento e funzionalità:

- `<it-upload>` mostra una lista verticale dei file caricati con anteprima immagini, ideale per form che richiedono uno o più allegati;
- `<it-upload-avatar>` crea il campo di caricamento di una foto profilo circolare e mostra la relativa anteprima, ideale per impostazioni account o profilo utente;
- `<it-upload-drag-drop>` predisponde un'area di trascinamento per il caricamento di file, adatto a flussi che richiedono un'esperienza più guidata.

Questi componenti delegano la selezione dei file a un `<input type="file">` nativo, accessibile da tastiera e compatibile con le tecnologie assistive. In `<it-upload-avatar>` e `<it-upload-drag-drop>` l'input è nascosto visivamente ma rimane accessibile ai lettori di schermo tramite l'etichetta ARIA associata.

I componenti supportano la validazione nativa HTML: aggiungi l'attributo `required` per rendere il campo obbligatorio all'interno di un `<form>`. Assegna sempre un `name` significativo per identificare il campo nei dati del form.

Gli attributi condivisi dai componenti sono:
- `name`, identifica il nome del campo, inviato con il valore nella sottomissione del form;
- `required`, rende il campo obbligatorio;
- `disabled`, disabilita il componente e ne impedisce l'interazione;
- `accept`, limita i tipi di file accettati (ad esempio, `"image/*"`, `".pdf,.docx"`).

Per `<it-upload>`, includi sempre un'etichetta nello slot `label` (`<span slot="label">Carica documenti</span>`): il componente la usa come testo del pulsante e come nome accessibile del campo.

Se vuoi modificare l'icona del pulsante di `<it-upload>`, usa un componente `<it-icon>` di tua scelta nello slot `icon` per sostituire l'icona predefinita.

## Accessibilità

I componenti Upload supportano la navigazione da tastiera, la navigazione tramite lettori di schermo e le best practice ARIA.

- In `<it-upload>`, il testo dello slot `label` è usato sia come etichetta visibile sia come nome accessibile dell'input nativo. Il componente emette un avviso in console se l'etichetta manca.
- In `<it-upload-avatar>`, l'etichetta dell'input file è generata automaticamente tramite il sistema i18n del componente.
- In `<it-upload-drag-drop>`, l'area di drop espone `role="region"` con un nome accessibile; il link "selezionalo dal dispositivo" consente la selezione da tastiera senza necessità di trascinamento.


Per garantire l'accessibilità dei componenti:
- aggiungi sempre un'etichetta descrittiva per ogni campo upload;
- usa l'attributo `support-text` di `<it-upload>` per informare l'utente sui requisiti del campo (formati accettati, dimensione massima) prima dell'interazione;
- per `<it-upload-drag-drop>`, completa sempre il ciclo di caricamento via JavaScript (progresso, successo o errore): lo stato viene comunicato esplicitamente anche agli utenti di lettori di schermo.

### Stati di caricamento

Ogni file nella lista può trovarsi in uno di questi stati: 
- `loading`, con la percentuale di avanzamento del caricamento; 
- `success`, quando il caricamento è completato;
- `error`, quando il caricamento è fallito.

Per i file in stato `success`, il componente mostra un pulsante X che permette di rimuoverli dalla lista. In questo modo, l'utente può correggere la selezione senza dover inviare di nuovo il form.

Per gestire la lista programmaticamente, usa i metodi `addFile()`, `setFileStatus()` e `setFileThumbnail()`. [Approfondisci nella sezione Proprietà, metodi ed eventi](proprietà-metodi-ed-eventi-accessibili-via-js)

### Con anteprima immagini

Per il caricamento di file immagini, aggungi `#image-preview` per mostrare una miniatura (thumbnail) al posto dell'icona generica di un file.

Il componente adatta la visualizzazione anche alle immagini con proporzioni diverse da quelle quadrate. Ti consigliamo comunque di caricare immagini di dimensioni e peso contenuti.

### Gestione automatica e manuale dello stato

Il componente supporta due modalità per gestire il caricamento.

**Modalità automatica (consigliata per casi semplici** 

Il componente gestisce automaticamente l'avvio e lo stato indeterminato:
- al completamento del **dragenter**, emette l'evento annullabile `it-dd-start`. Se non prevenuto, chiama `start()` e mostra l'indicatore di progresso indeterminato;
- al completamento del **drop** (o selezione da file input), emette l'evento annullabile `it-dd-drop`. Se non prevenuto, chiama `start()` e attiva la visualizzazione indeterminata.

**Modalità manuale (per scenari complessi)** 

Puoi gestire direttamente ogni fase del processo di caricamento:
- ascolta gli eventi `it-dd-start` e `it-dd-drop`;
- chiama `e.preventDefault()` per annullare il comportamento automatico;
- invoca manualmente `el.start()`, `el.progress(value)`, `el.success()`, oppure `el.reset()` nei tempi che preferisci.

Esempio di controllo manuale:

```js
const dd = document.getElementById('my-upload');

// Annulla il comportamento automatico e gestisci manualmente
dd.addEventListener('it-dd-drop', (event) => {
  event.preventDefault();

  // Inizia il caricamento
  dd.start();

  // Simula la progressione
  let progress = 0;
  const interval = setInterval(() => {
    progress += 0.1;
    dd.progress(Math.min(progress, 1));

    if (progress >= 1) {
      clearInterval(interval);
      // Completa l'operazione
      dd.success();
    }
  }, 500);
});
```

Lo stato di success dipende dal caricamento corretto del file sul server e va quindi gestito da chi svilupperà il front-end/back-end del sito o della web app.

Per tornare allo stato iniziale (inattivo, senza file selezionato, progresso a 0), chiama `el.reset()`.

## Integrazione form e validazione

I componenti Upload supportano la validazione nativa HTML tramite il meccanismo `FormControlController`. Aggiungendo l'attributo `required` il campo impedisce l'invio del form se non è valorizzato.

Per `<it-upload-avatar>`, se `src` è già valorizzato, il requisito è soddisfatto anche senza un nuovo caricamento: l'immagine esistente è considerata un valore valido.

## Personalizzazione degli stili

Puoi personalizzare lo stile interno dei componenti tramite il selettore `::part`.

Per it-upload, usa:
- **`input-label`**, per il pulsante/etichetta "Carica file" (elemento `<label>` associato all'input);
- **`file-remove-button`**, per il pulsante di rimozione dei file caricati nella variante Lista verticale;
- **`gallery-remove-button`**, per pulsante di rimozione delle immagini nella variante Gallery.

Per it-upload-avatar, usa:
- **`overlay-label`**, per 'etichetta che appare in overlay sopra l'avatar al passaggio del mouse / focus.

Per it-upload-drag-drop, usa:
- **`drop-zone`**, per l'area di trascinamento principale (il `<div role="region">`).

[Vai alla guida sul selettore part](/docs/personalizzazione-degli-stili--documentazione#selettore-part)
