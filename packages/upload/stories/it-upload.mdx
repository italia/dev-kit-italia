# Upload

<description>Campo per la selezione e il caricamento di file.</description>

## Cosa fa

Il componente Upload (`<it-upload>`) permette di caricare uno o più file tramite selezione o drag & drop, mostrando l'anteprima delle immagini e gli stati di avanzamento.

[Approfondisci come e quando usare il componente Upload](https://designers.italia.it/design-system/componenti/upload/)

## Indicazioni generali

Scegli tra 3 componenti distinti in base alle esigenze di caricamento e funzionalità:

- `<it-upload>` mostra una lista verticale dei file caricati con anteprima immagini, ideale per form che richiedono uno o più allegati;
- `<it-upload-avatar>` crea il campo di caricamento di una foto profilo circolare e mostra la relativa anteprima, ideale per impostazioni account o profilo utente;
- `<it-upload-drag-drop>` predisponde un'area di trascinamento per il caricamento di file, adatto a flussi che richiedono un'esperienza più guidata.

Ognuno dei tre componenti delega la selezione dei file a un `<input type="file">` nativo, accessibile da tastiera e compatibile con le tecnologie assistive. In `<it-upload-avatar>` e `<it-upload-drag-drop>` l'input è nascosto visivamente ma rimane accessibile ai lettori di schermo tramite l'etichetta ARIA associata.

Tutti e tre i componenti supportano la validazione nativa HTML: aggiungi l'attributo `required` per rendere il campo obbligatorio all'interno di un `<form>`. Assegna sempre un `name` significativo per identificare il campo nei dati del form.

Gli attributi condivisi dai 3 componenti sono:
- `name`, identifica il nome del campo, inviato con il valore nella sottomissione del form;
- `required`, rende il campo obbligatorio;
- `disabled`, disabilita il componente e ne impedisce l'interazione;
- `accept`, limita i tipi di file accettati (ad esempio, `"image/*"`, `".pdf,.docx"`).

Per `<it-upload>`, includi sempre un'etichetta nello slot `label` (`<span slot="label">Carica documenti</span>`): il componente la usa come testo del pulsante e come nome accessibile del campo.

Se vuoi modificare l'icona del pulsante di `<it-upload>`, usa un componente `<it-icon>` di tua scelta nello slot `icon` per sostituire l'icona predefinita.

## Accessibilità

I 3 componenti Upload sono progettati per supportare la navigazione da tastiera, gli screen reader e le best practice ARIA.

In particolare:
- In `<it-upload>`, il testo dello slot `label` è usato sia come etichetta visibile sia come nome accessibile dell'input nativo. Il componente emette un avviso in console se l'etichetta manca.
- In `<it-upload-avatar>`, l'etichetta dell'input file è generata automaticamente tramite il sistema i18n del componente.
- In `<it-upload-drag-drop>`, l'area di drop espone `role="region"` con un nome accessibile; il link "selezionalo dal dispositivo" consente la selezione da tastiera senza necessità di trascinamento.


Per garantire l'accessibilità dei componenti Upload, segui queste linee guida:
- Fornisci sempre un'etichetta descrittiva per ogni campo upload.
- Usa l'attributo `support-text` di `<it-upload>` per informare l'utente sui requisiti del campo (formati accettati, dimensione massima) prima dell'interazione.
- Per `<it-upload-drag-drop>`, completa sempre il ciclo di caricamento via JavaScript (progresso, successo o errore): lo stato viene comunicato esplicitamente anche agli utenti di screen reader.

## Con anteprima immagini

Aggiungi `#image-preview` per sostituire l'icona generica che rappresenta un file con un'anteprima thumbnail delle immagini caricate: è consigliato quando il campo accetta prevalentemente immagini.

Il componente ottimizza la visualizzazione delle immagini anche quando queste non hanno proporzione quadrata, si consiglia comunque di utilizzare immagini dal peso contenuto.

Ogni file nella lista può trovarsi in uno dei seguenti stati: `loading` (con percentuale di avanzamento), `success` (caricamento completato) o `error` (caricamento fallito).

I file in stato `success` possono essere rimossi tramite il pulsante X aggiuntivo: l'utente può così correggere la selezione senza dover ricaricare il form.

Usa i metodi `addFile()`, `setFileStatus()` e `setFileThumbnail()` per gestire la lista programmaticamente — consulta la sezione **Proprietà, Metodi ed Eventi** per i dettagli.

### Gestione automatica e manuale dello stato

Il componente supporta due modalità per gestire il caricamento:

**Modalità automatica (consigliata per casi semplici):** Il componente auto-gestisce l'avvio e lo stato indeterminato
- Al completamento del **dragenter**: emette l'evento annullabile `it-dd-start`. Se non prevenuto, chiama `start()` e mostra l'indicatore di progresso indeterminato.
- Al completamento del **drop** (o selezione da file input): emette l'evento annullabile `it-dd-drop`. Se non prevenuto, chiama `start()` e attiva la visualizzazione indeterminata.

**Modalità manuale (per scenari complessi):** Tu assumi il controllo totale del ciclo di caricamento
- Ascolta gli eventi `it-dd-start` e `it-dd-drop`
- Chiama `e.preventDefault()` per annullare il comportamento automatico
- Invoca manualmente `el.start()`, `el.progress(value)`, `el.success()`, oppure `el.reset()` nei tempi che preferisci

Esempo di controllo manuale:

```js
const dd = document.getElementById('my-upload');

// Annulla il comportamento automatico e gestisci manualmente
dd.addEventListener('it-dd-drop', (event) => {
  event.preventDefault();

  // Inizia il caricamento
  dd.start();

  // Simula la progressione
  let progress = 0;
  const interval = setInterval(() => {
    progress += 0.1;
    dd.progress(Math.min(progress, 1));

    if (progress >= 1) {
      clearInterval(interval);
      // Completa l'operazione
      dd.success();
    }
  }, 500);
});
```

Lo stato di success dipende dal caricamento corretto del file sul server e va quindi gestito da chi svilupperà il front-end/back-end del sito o webapp.

Per tornare allo stato iniziale (inattivo, senza file selezionato, progresso a 0), chiama `el.reset()`.

## Integrazione form e validazione

Tutti e tre i componenti partecipano alla validazione nativa HTML tramite il meccanismo `FormControlController`. Aggiungendo l'attributo `required` il campo impedisce l'invio del form se non è valorizzato.

Per `<it-upload-avatar>`, se `src` è già valorizzato, il requisito è soddisfatto anche senza un nuovo caricamento: l'immagine esistente è considerata un valore valido.

## Personalizzazione degli stili

Puoi personalizzare lo stile interno dei componenti tramite il selettore `::part`.

[Vai alla guida sul selettore part](/docs/personalizzazione-degli-stili--documentazione#selettore-part)

### it-upload

- **`input-label`** - Il pulsante/etichetta "Carica file" (elemento `<label>` associato all'input).
- **`file-remove-button`** - Il pulsante di rimozione di ogni riga nella lista file.
- **`gallery-remove-button`** - Il pulsante di rimozione circolare su ogni immagine nella gallery.

### it-upload-avatar

- **`overlay-label`** - L'etichetta overlay che copre l'avatar al passaggio del mouse / focus.

### it-upload-drag-drop

- **`drop-zone`** - L'area di trascinamento principale (il `<div role="region">`).
