# Upload

<description>Elementi dei form dedicati al caricamento file</description>

## Cosa fa

Il componente Upload consente l'upload di file attraverso diverse modalità: lista verticale, anteprima immagini, gallery, avatar, o drag & drop.

[Approfondisci come e quando usare il componente Upload](https://designers.italia.it/design-system/componenti/upload/)

Il componente `<it-upload>` mostra i file caricati in una lista verticale con icone file e la possibilità di rimozione singola.

<Canvas of={Stories.UploadConListaDiFile} />

### Anteprima immagini

Aggiungendo l'attributo `image-preview`, le immagini caricate mostrano un'anteprima thumbnail al posto dell'icona generica. È consigliato quando il campo accetta prevalentemente immagini.

### Stati dei file

Ogni file nella lista può trovarsi in uno dei seguenti stati: `loading` (con percentuale di avanzamento), `success` (caricamento completato) o `error` (caricamento fallito).

Usa i metodi `addFile()`, `setFileStatus()` e `setFileThumbnail()` per gestire la lista programmaticamente — consulta la sezione **{Stories.MetodiEPropPubblici.name}** per i dettagli.

<Canvas of={Stories.UploadConStatoFile} />

### Upload Gallery

Con `variant="gallery"` le foto caricate vengono visualizzate in una griglia a "pictures wall", ideale per gestire upload multipli di immagini.

## Upload con Avatar

Il componente `<it-upload-avatar>` combina la visualizzazione di un avatar circolare con un input file per permettere il caricamento di una foto profilo.

Modifica gli attributi nella tabella per personalizzare il componente.

<Canvas of={Stories.EsempioInterattivoAvatar} />
<Controls of={Stories.EsempioInterattivoAvatar} />

Sono disponibili due dimensioni tramite l'attributo `size`: `xxl` (standard) e `xl` (piccola). Aggiorna l'avatar selezionando un nuovo file: l'anteprima viene aggiornata immediatamente nel componente.

<Canvas of={Stories.UploadConAvatar} />

## Upload Drag & Drop

Il componente `<it-upload-drag-drop>` consente di caricare un file trascinandolo sull'area dedicata oppure tramite la selezione manuale.

Modifica gli attributi nella tabella per personalizzare il componente.

<Canvas of={Stories.EsempioInterattivoDragDrop} />
<Controls of={Stories.EsempioInterattivoDragDrop} />

Lo stato del caricamento è rappresentato da un indicatore di progresso circolare (ciambella). Chiama `el.progress(value)` passando un valore compreso tra 0 e 1 per aggiornare il progresso; il componente converte automaticamente il valore in percentuale. Al termine chiama `el.success()` per mostrare lo stato completato. Chiama `el.reset()` per tornare allo stato iniziale.

<Canvas of={Stories.UploadDragDrop} />

## Integrazione form e validazione

Tutti e tre i componenti partecipano alla validazione nativa HTML tramite il meccanismo `FormControlController`. Aggiungendo l'attributo `required` il campo impedisce l'invio del form se non è valorizzato.

Per `<it-upload-avatar>`, se `src` è già valorizzato, il requisito è soddisfatto anche senza un nuovo caricamento: l'immagine esistente è considerata un valore valido.
