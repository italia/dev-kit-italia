# Come contribuire

Puoi contribuire allo sviluppo di Dev Kit Italia testando la libreria nel tuo ambiente di lavoro, verificandone l'integrazione con diversi framework JavaScript e segnalando eventuali problemi o proponendo miglioramenti tramite GitHub.

## Installare la libreria in locale

Per installare la libreria e avviare Storybook in locale, devi aver installato <a href="https://nodejs.org/" target="_blank" rel="noopener noreferrer" style={{ display: 'inline-flex', alignItems: 'center', gap: '0.25rem' }}>Node.js<span className="visually-hidden"> (link esterno, si apre in una nuova scheda)</span><it-icon name="it-external-link" size="sm" color="primary" aria-hidden="true" style={{ transform: 'translateY(-2px)' }}></it-icon></a> e <a href="https://pnpm.io/" target="_blank" rel="noopener noreferrer" style={{ display: 'inline-flex', alignItems: 'center', gap: '0.25rem' }}>pnpm<span className="visually-hidden"> (link esterno, si apre in una nuova scheda)</span><it-icon name="it-external-link" size="sm" color="primary" aria-hidden="true" style={{ transform: 'translateY(-2px)' }}></it-icon></a>.

Per installare le dipendenze:

```bash
pnpm install
```

Per compilare tutti i componenti:

```bash
pnpm build
```

Per avviare Storybook in locale:

```bash
pnpm storybook
```

### Durante lo sviluppo

- Documentazione/Storie e tipi: si aggiornano automaticamente ✨
- Componenti: puoi ricompilare il solo package modificato

```bash
# Per esempio, se stai modificando il componente button:
pnpm build --filter=@italia/button
# Poi ricarica la pagina del browser
```

## Testare l'integrazione in altri framework JS

1. Crea un progetto di esempio con il framework desiderato:

```bash
# Esegui questo comando
npm create vite@latest test-app
# Poi segui il prompt!
```

2. Dopo aver creato il progetto, installa Dev Kit Italia come dipendenza:

```bash
npm install @italia/dev-kit-italia
```

3. Importa i componenti nel progetto:

```javascript
import '@italia/dev-kit-italia/fonts.css';
import '@italia/dev-kit-italia/styles.css';
import '@italia/dev-kit-italia/elements.js';

// Pronti a utilizzare i Web Components!
return (
  <div>
    <it-button ...></it-button>
  </div>
)
```

Come alternativa, puoi installare i singoli pacchetti dei componenti. Dovrai comunque importare il file CSS generale come mostrato sopra.

```bash
npm install @italia/button @italia/dev-kit-italia
```

```javascript
import '@italia/dev-kit-italia/fonts.css';
import '@italia/dev-kit-italia/styles.css';
import '@italia/button/it-button.js';

return (
  <div>
    <it-button ...></it-button>
  </div>
)
```

## Applicazioni predefinite per il testing

Nella cartella `/examples` trovi alcune applicazioni create con i framework **Angular**, **React**, **Svelte** e **Vue** con cui puoi testare l'attuale versione della libreria (o del branch corrente).

### Come testare

1. Compila sempre la versione corrente della libreria posizionandoti nella root con:

```bash
pnpm install # Per installare tutte le dipendeze dei vari packages
pnpm build
```

2. Posizionati nella cartella del framework che vuoi testare. Ad esempio, per testare il framework React (oppure Vue o Svelte):

```bash
cd examples/react-app
npm install # Per copiare nella node_modules la versione compilata di dev-kit-italia
npm run dev
```

Se invece vuoi testare l'app Angular, esegui:

```bash
cd examples/angular-app
npm install # Per copiare nella node_modules la versione compilata di dev-kit-italia
npm start
```
