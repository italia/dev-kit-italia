## Cosa fa

Il componente Sidebar permette di navigare tra le pagine che appartengono a una sezione di un sito. A seconda dell'organizzazione dei contenuti, la barra di navigazione può presentare liste di link diretti o annidati sotto una voce che li raccoglie.

[Approfondisci quando e come usare il componente Sidebar](https://designers.italia.it/design-system/componenti/sidebar/)

### Alternative a questo componente
- [Tabs](/docs/componenti-tabs--documentazione) : per offrire un’esperienza di navigazione semplificata, sopratutto in caso di poche pagine o contenuti.
- [Navscroll](/docs/componenti-navscroll--documentazione): per fornire una navigazione veloce tra i contenuti presenti all’interno di una stessa pagina (navigazione tramite ancore).

## Anteprima e attributi del componente

## Accessibilità

Il componente Sidebar segue le migliori pratiche di accessibilità e garantisce una navigazione intuitiva e fruibile per tutte le persone.
Negli esempi `.sidebar-wrapper` è un elemento `<aside>`, con il titolo come nome tramite `aria-labelledby`: usalo se nella pagina la sidebar è un contenuto complementare.

Per garantire un'esperienza accessibile, assicurati di:

- usare un `<nav>` per ogni lista di link (`.link-list-wrapper`) e, quando nella pagina ci sono più `<nav>`, dare a ciascuno un `aria-label` distinto che ne indichi la funzione;
- non inserire il titolo come elemento `<li>`, perché verrebbe contato tra gli elementi della lista: posizionarlo prima della lista, all'inizio di `.sidebar-wrapper` come negli esempi, oppure dentro il `<nav>` della lista, usandolo come nome del `<nav>` tramite `aria-labelledby` al posto di `aria-label`;
- assegnare al titolo un `id` unico nella pagina quando è usato come nome tramite `aria-labelledby`;
- indicare sempre **visivamente** la pagina corrente, usando la classe `.active` sul link corrispondente;
- indicare sempre **alle tecnologie assistive** la pagina corrente, usando l'attributo `aria-current="page"` sul link corrispondente;
- segnalare i link disabilitati alle tecnologie assistive, usando l'attributo `aria-disabled="true"`;
- usare il componente `<it-collapse>` per le liste collassabili, che gestisce automaticamente gli attributi ARIA necessari (`aria-expanded`, `aria-controls`, `role`);
- disabilitare via JavaScript la navigazione dei link/collapse disabilitati per evitare comportamenti inattesi: le diverse varianti forniscono un'implementazione di esempio.


## Sidebar con icone

Per aggiungere icone alla lista di link contenuta nella sidebar, usa il componente `<it-icon>` all'interno dei link con classe `.icon-left`.

## Sidebar con linea a destra

Per creare una sidebar con linea separatrice a destra, aggiungi la classe `.it-line-right-side` a `<aside class="sidebar-wrapper">`.

## Sidebar con linea a sinistra

Per creare una sidebar con linea separatrice a sinistra, aggiungi la classe `.it-line-left-side` a `<aside class="sidebar-wrapper">`.

<Canvas of={SidebarStories.SidebarLineaSinistra} />

## Sidebar annidata

Una sidebar può contenere una lista di link primaria annidata, tramite la classe `.link-sublist` per le sotto-liste espanse.

Per rendere collassabili le sottosezioni della sidebar, usa il componente `<it-collapse>` integrato nelle liste di navigazione. Il componente `<it-collapse>` permette di espandere e comprimere le sottosezioni in modo interattivo, migliorando l'esperienza di navigazione su sidebar con molte voci.

Consulta la [documentazione del componente Collapse](/docs/componenti-collapse--documentazione) per maggiori dettagli sull'uso di `<it-collapse>`.
