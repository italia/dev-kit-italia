# Form

<description>Contenitore di campi input aggregati per la raccolta di dati e la configurazione di opzioni.</description>

## Cosa fa
Il componente Form raggruppa campi input correlati in un modulo, utile per l'invio di informazioni o la configurazione di opzioni. Puoi subordinare l'invio del modulo alla compilazione di tutti i campi obbligatori e alla validazione dei dati secondo formati specifici.

[Approfondisci come e quando usare il componente Form](https://designers.italia.it/design-system/componenti/form/)

## Organizzazione dei campi

Gli elementi del form sono disposti in verticale per impostazione predefinita. Puoi modificare questo layout usando classi aggiuntive.

Bootstrap Italia applica automaticamente a tutti i form le proprietà `display: block` e `width: 100%`.

### Dimensionamento delle colonne in layout complessi

Per creare layout più complessi, con più colonne, larghezze diverse e opzioni di allineamento particolari, puoi utilizzare il sistema a griglia.

- Applica la classe `.row` all'elemento HTML contenitore (ad esempio, un `<div>`) per gestire correttamente la spaziatura tra gli elementi.

- Puoi assegnare una larghezza specifica a una colonna con l'attributo `.col-md-*` (ad esempio, con `.col-md-6` per farle occupare metà dello spazio disponibile a partire dal breakpoint `md` di 768px in poi). Le restanti colonne con classe `.col-md` si divideranno lo spazio rimanente.

- Puoi applicare la classi `.col-md-*` sia a un elemento HTML contenitore (ad esempio, un `<div>`), sia direttamente a un campo input (ad esempio, `<it-input class="col-md-6">`).

### Autodimensionamento

Per far ridimensionare automaticamente le colonne in base al contenuto, puoi usare le [classi CSS Flexbox](https://italia.github.io/bootstrap-italia/docs/organizzare-gli-spazi/flex/). Puoi usarle anche in combinazione con colonne di dimensioni specifiche. 

Nell’esempio, la classe CSS Flexbox ha centrato il contenuto verticalmente dal breakpoint `lg` in poi e cambiato `.col` con `.col-auto` per far occupare alle colonne solo lo spazio necessario.

## Validazione
I componenti per i campi di un from (ad esempio, `<it-input>`) supportano la validazione standard del browser a seconda del tipo di campo e/o degli attributi `minlength`, `maxlength`, `pattern` e `required`.

### Validazione custom

Per personalizzare la validazione di un campo (lato server o con JS), imposta l' attributo `custom-validation="true"`. La validazione predefinita del componente verrà disabilitata.

Ricorda di impostare un messaggio di errore chiaro e conciso attraverso l'attributo `validity-message="Messaggio di errore"`.

### Validazione via JS

Per implementare una validazione personalizzata via JS, intercetta gli eventi emessi dai componenti:

```js
 window.addEventListener('DOMContentLoaded', () => {
      const form = document.querySelector('#form');
      const all_input = form.querySelectorAll('it-input');

      // evento scatenato quando il web-component ha effettutato il primo render, e l'input è disonibile nel DOM
      all_input.forEach(input=>{
        input.addEventListener('it-input-ready', (event) => {
          const input = event.detail.el;
          // il tuo codice qui.
        });
      });

      // evento scatenato quando l'input riceve l'evento di 'it-input' (ad esempio, durante l'inserimento di testo da parte dell'utente)
      all_input.forEach(i=>{
        i.addEventListener('it-input', (event) => {
          const input = event.detail.el;
          // il tuo codice qui.
        });
      });

      form.addEventListener('submit', (e) => {
        e.preventDefault();
        // il tuo codice qui.
      });
    });
```
