## Cosa fa

Il componente List, in italiano lista, raggruppa in una lista verticale una serie di contenuti correlati.

[Approfondisci come e quando usare il componente List](https://designers.italia.it/design-system/componenti/list/)

### Alternative a questo componente

- [Tables](/docs/componenti-tables--documentazione): le tabelle sono utili a mostrare set di dati più complessi.
- [Dropdown](/docs/componenti-dropdown--documentazione): utili per creare menu contestuali di navigazione laddove le scelte siano limitate.

## Tipologie di lista

Le liste, costituite da tag `<ul>` con classe `.it-list` all'interno di un wrapper con classe `.it-list-wrapper`, possono contenere testi, link, icone, avatar, immagini o una combinazione di questi elementi.

### Lista con avatar

Per aggiungere un avatar, inserisci l'elemento `it-avatar` prima dell'elemento `.it-right-zone` che contiene il testo.

<Canvas of={ListStories.ListaConAvatar} />

### Lista con icona

Per aggiungere un'icona, inserisci l'elemento `.it-rounded-icon` con all'interno la relativa icona prima dell'elemento `.it-right-zone` che contiene il testo.

<Canvas of={ListStories.ListaConIcona} />

### Lista con immagine

Per aggiungere un'immagine, inserisci l'elemento `.it-thumb` con all'interno la relativa immagine prima dell'elemento `.it-right-zone` che contiene il testo.
L'immagine ha una dimensione massima di `5rem`, che corrispondono a `80px`.
Puoi modificare le proporzioni dell'immagine usando utilizzando le [classi specifiche per le proporzioni](https://designers.italia.it/design-system/fondamenti/proporzioni-media/).

<Canvas of={ListStories.ListaConImmagine} />

## Lista con azioni

Le liste con azioni presentano icone o elementi interattivi associati all'azione stessa.

### Con freccia

Per aggiungere una freccia, inserisci l'elemento `it-icon` dopo l'elemento `.text` che contiene il testo.

<Canvas of={ListStories.ListaConFreccia} />

### Con azioni multiple

Per aggiungere più azioni, inserisci l'elemento `.it-multiple` con all'interno le relative icone dopo l'elemento `.text`.

<Canvas of={ListStories.ListaConAzioniMultiple} />

## Altre varianti

### Con metadata

Per aggiungere un campo testuale di metadati, inserisci l'elemento `.metadata` dopo l'elemento `.text`.

<Canvas of={ListStories.ListaConMetadata} />

### Con testo aggiuntivo, azioni multiple e metadata

Per aggiungere testo aggiuntivo ad ogni elemento della lista, usa titolo (heading) e paragrafo `<p>`, mantenendo la classe `.text` per l'elemento titolo.
Includi entrambi in un elemento `<div>` per allinearli correttamente.

## Liste per menu di navigazione

Per creare le voci di un megamenu, una sidebar o una navscroll, usa il tag `<ul>` con classe `.link-list` all'interno di un wrapper con classe `.link-list-wrapper`.

### Linea singola

<Canvas of={ListStories.LinkListLineaSingola} />

#### Elemento con stato attivo

Per attivare un elemento, aggiungi la classe `.active` al relativo link.

<Canvas of={ListStories.LinkListElementoAttivo} />

#### Elemento con stato disabilitato

Per disabilitare un elemento, aggiungi la classe `.disabled` al relativo link.

<Canvas of={ListStories.LinkListElementoDisabilitato} />

#### Intestazione e divisore

Puoi aggiungere un'intestazione (con o senza link) e/o divisori per separare gruppi di link.

L'intestazione è costituita dall'elemento `.link-list-heading` che precede il tag `<ul>`.
Il divisore è costituito dal tag `<span>` con classe `.divider` e attributo `role="separator"` all'interno del tag `<li>`.

<Canvas of={ListStories.LinkListIntestazioneConLink} />

### Dimensioni

Per ogni elemento di una lista di link puoi definire una variante di dimensione maggiore usando la classe `.large` applicata al tag `<a>`.

<Canvas of={ListStories.LinkListDimensioni} />

### Multiline con icona

Puoi aggiungere un'icona (a destra o sinistra del testo) e un abstract per ogni elemento di una lista di link.

Per includere un'icona, aggiungi al tag `<a>` una delle seguenti classi:

- `icon-right`, per posizionare l'icona a destra del testo;
- `icon-left`, per posizionare l'icona a sinistra del testo.

Puoi inserire [l'icona necessaria](/docs/componenti-icon--documentazione) all'interno del tag `<span class="list-item-title-icon-wrapper">`, subito dopo o prima dello `<span class="list-item-title">` contenente il testo.

<Canvas of={ListStories.LinkListMultilineIcona} />

### Lista con controlli

Le liste di link con controlli sono caratterizzate da icone a destra e sinistra del testo.
Quella di destra è descrittiva mentre quella di sinistra può essere un'eventuale azione aggiuntiva da gestire in JavaScript.

Aggiungi al tag `<a>` la classe `.icon-right` per posizionare l'icona a destra del testo, oppure la classe `.icon-left` per posizionare l'icona a sinistra del testo.

#### Azione primaria

##### Icona a sinistra

Inserisci [l'icona necessaria](/docs/componenti-icon--documentazione) all'interno del tag `<span class="list-item-title-icon-wrapper">`, subito prima del tag `<span class="list-item-title">` contenente il testo.
Per posizionarla correttamente a sinistra del testo, aggiungi la classe `.icon-left` al tag `<a>`.

<Canvas of={ListStories.LinkListControlliIconaSinistra} />

#### Azione secondaria

##### Icona a destra

Inserisci [l'icona necessaria](/docs/componenti-icon--documentazione) all'interno del tag `<span class="list-item-title-icon-wrapper">`, subito dopo il tag `<span class="list-item-title">` contenente il testo.
Per posizionarla correttamente a destra del testo, aggiungi la classe `.icon-right` al tag `<a>`.

<Canvas of={ListStories.LinkListControlliIconaDestra} />

#### Azioni primaria e secondaria

##### Icona a sinistra

Inserisci l'icona all'interno del tag `<span class="list-item-title-icon-wrapper">`, subito prima del tag `<span class="list-item-title">` contenente il testo.
Per posizionarla a sinistra del testo, aggiungi la classe `.icon-left` al tag `<a>`.

##### Icona a destra

Inserisci l'icona all'interno del tag `<span class="list-item-title-icon-wrapper">`, subito dopo del tag `<span class="list-item-title">` contenente il testo.
Per posizionarla a destra del testo, aggiungi la classe `.icon-right` al tag `<a>`.

<Canvas of={ListStories.LinkListControlliDoppiaIcona} />
