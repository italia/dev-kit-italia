# Font

È necessario anche includere i file relativi ai caratteri tipografici referenziati nel CSS della libreria. L’inclusione dei font può avvenire includendo il bundle fornito dal pacchetto `@italia/dev-kit-italia`, oppure utilizzando CSS.

Dev Kit Italia include tre famiglie di caratteri tipografici:

- **Titillium** (Web o Sans Pro): font principale sans-serif per interfacce e testi brevi
- **Lora**: font serif per contenuti editoriali e testi lunghi
- **Roboto Mono**: font monospace per codice, dati tabulari e numeri

## Titillium: il font principale

Dev Kit Italia include due varianti del carattere sans-serif Titillium con licenza aperta:

- **Titillium Web**: versione originale e default, è il carattere di riferimento del Design system .italia ([storia del font Titillium e crediti](https://nta.accademiadiurbino.it/titillium/)).
- **Titillium Sans Pro**: evoluzione del Titillium Web con supporto linguistico esteso e scrittura matematica ([repository Titillium Sans Pro e crediti](https://github.com/chialab/titillium_pro/tree/main)).

Per scegliere quale delle due varianti usare come font principale, importa uno dei due file CSS dei font disponibili nel bundle: sono equivalenti, contengono entrambi Lora e Roboto Mono, e differiscono solo per la variante di Titillium inclusa. Non serve nessuna configurazione aggiuntiva: la tipografia della libreria usa già di default il carattere sans-serif disponibile, quindi importando solo uno dei due file il browser userà automaticamente la variante di Titillium presente.

- `fonts.css`: Titillium Web (default) + Lora + Roboto Mono
- `fonts-sans-pro.css`: Titillium Sans Pro + Lora + Roboto Mono

Non importare entrambi i file insieme: se sono presenti i `@font-face` di entrambe le varianti, viene sempre applicata Titillium Web, che è la prima della lista di fallback.

Usa il selettore font nella toolbar di Storybook (in alto) per esplorare la resa delle due varianti su tutta la documentazione, in tempo reale.

Ulteriori informazioni sull'uso dei font nella scheda [Tipografia](/docs/organizzare-i-contenuti-tipografia--documentazione).

## Carica via bundle

È disponibile il bundle dei font relativo alla variante di Titillium scelta, includibile con:

```html
<!-- Titillium Web (default) -->
<link rel="stylesheet" href="dev-kit-italia/fonts.css" />

<!-- oppure, Titillium Sans Pro -->
<link rel="stylesheet" href="dev-kit-italia/fonts-sans-pro.css" />
```

## Carica via CSS

È possibile caricare i font via CSS. Per semplicità abbiamo utilizzato la sintassi SCSS in modo da utilizzare una variabile per specificare il percorso `$font-path` dove trovare i file dei font. Include il blocco `@font-face` di Lora e Roboto Mono insieme a **una sola** delle due varianti di Titillium.
