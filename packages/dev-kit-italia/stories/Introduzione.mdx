## Cos'è Dev Kit Italia

Dev Kit Italia è una risorsa open source che offre **Web Components nativi HTML**, pronti all'uso, per sviluppare interfacce per i servizi della Pubblica Amministrazione. 

Questo kit si basa sul [Design system Italia](https://designers.italia.it/design-system/) ed evolve le attuali librerie di sviluppo [Bootstrap Italia](https://italia.github.io/bootstrap-italia/), [Design React Kit](https://italia.github.io/design-react-kit/latest/?path=/docs/documentazione-welcome--documentazione) e [Design Angular Kit](https://italia.github.io/design-angular-kit) verso un sistema più flessibile, duraturo e indipendente.

[Vai al repository GitHub](https://github.com/italia/dev-kit-italia)

L'uso dei Web Components permette di:

- usare gli stessi componenti in **qualsiasi ambiente** di sviluppo;
- **ridurre** la manutenzione del codice e il **debito tecnico**;
- garantire **accessibilità** (WCAG 2.2) e uniformità visiva;
- facilitare la **personalizzazione** tramite design token integrati.

## Come iniziare

1. Installa il pacchetto `npm` con questo comando:

```bash
npm install @italia/dev-kit-italia
```

2. Importa le risorse necessarie nel tuo progetto:

```javascript
import '@italia/dev-kit-italia/fonts.css';
import '@italia/dev-kit-italia/styles.css';
import '@italia/dev-kit-italia/elements.js';

// Pronti a utilizzare i Web components!
return (
  <div>
    <it-button ...></it-button>
  </div>
)
```

In alternativa, puoi installare i singoli pacchetti dei componenti. Anche in questo caso dovrai importare il file CSS generale.

```bash
npm install @italia/button @italia/dev-kit-italia
```

```javascript
import '@italia/dev-kit-italia/fonts.css';
import '@italia/dev-kit-italia/styles.css';
import '@italia/button/it-button.js';

return (
  <div>
    <it-button ...></it-button>
  </div>
)
```
