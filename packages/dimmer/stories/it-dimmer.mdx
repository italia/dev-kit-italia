## Cosa fa

Il componente Dimmer può essere utilizzato per focalizzare l'attenzione dell'utente su un contenuto di particolare rilevanza, posizionandosi in sovrapposizione ad una porzione o sezione di pagina esistente.

### Alternative a questo componente
- [Notification](/docs/componenti-notification--documentazione): per comunicare all'utente il risultato di un'operazione o un cambiamento di stato del sistema.
- [Modal](/docs/componenti-modal--documentazione): quando l'utente deve compiere un'azione consapevole per proseguire.

[Approfondisci quando e come usare il Dimmer](https://designers.italia.it/design-system/componenti/dimmer/)

Inserisci il contenuto da oscurare nel **default slot**, e inserisci il contenuto dell'overlay nello **slot `content`**.

## Accessibilità

Il componente dimmer è progettato per essere accessibile, ma è importante seguire alcune linee guida per garantire un'esperienza accessibile:

- includi sempre una descrizione significativa nello slot `content` quando il dimmer è usato per comunicare un messaggio;
- se il dimmer contiene pulsanti d'azione, assicurati che abbiano etichette comprensibili;


## Varianti

Il dimmer supporta una variante cromatica primaria, con sfondo del colore primario, attivabile tramite l'attributo `variant="primary"`, e una variante scura `variant="dark"`.

### Variante primaria

Puoi utilizzare l'attributo `variant` con valore `"primary"` per ottenere una versione con sfondo del colore primario. Questa è anche la variante di default del dimmer nel caso in cui l'attributo `variant` non sia specificato.

## Proprietà, metodi ed eventi accessibili via js

Il componente espone dei metodi ed eventi utili per eventuali interazioni via js.

### Metodi

Il componente espone i seguenti metodi pubblici per la gestione programmatica:

- `show()` — mostra il dimmer;
- `hide()` — nasconde il dimmer;
- `toggle()` — alterna lo stato di visibilità.

```js
const dimmerEl = document.getElementById('myDimmer');

dimmerEl.show();   // mostra
dimmerEl.hide();   // nasconde
dimmerEl.toggle(); // alterna
```

<Canvas of={Stories.AttivazioneViaJS} />

### Eventi

Il componente emette i seguenti eventi custom:

- `it-dimmer-show`:  Emesso quando il dimmer diventa visibile
- `it-dimmer-hide`:  Emesso quando il dimmer viene nascosto

```js
const dimmerEl = document.getElementById('myDimmer');

dimmerEl.addEventListener('it-dimmer-show', (e) => {
  console.log('Dimmer visibile', e.detail.dimmer);
});

dimmerEl.addEventListener('it-dimmer-hide', (e) => {
  console.log('Dimmer nascosto', e.detail.dimmer);
});
```

## Personalizzazione degli stili

Per personalizzare gli stili usa il selettore `::part` con uno dei seguenti valori:

- `::part(dimmable)` — il wrapper che racchiude l'intero componente;
- `::part(dimmer)` — l'elemento overlay;
- `::part(dimmer-inner)` — il contenitore centrale del contenuto dell'overlay;
- `::part(dimmer-icon)` — il wrapper dell'icona (presente solo se `icon-name` è valorizzato);

[Vai alla guida sul selettore part](/docs/personalizzazione-degli-stili--documentazione#selettore-part).
