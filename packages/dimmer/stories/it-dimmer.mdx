## Cosa fa

Il componente Dimmer (`it-dimmer`) oscura una porzione della pagina per portare l’attenzione dell’utente su contenuti o azioni mostrati in sovrapposizione all’interfaccia.

[Approfondisci quando e come usare il componente Dimmer](https://designers.italia.it/design-system/componenti/dimmer/)

### Alternative a questo componente
- [Notification](/docs/componenti-notification--documentazione): per comunicare all'utente il risultato di un'operazione o un cambiamento di stato del sistema.
- [Modal](/docs/componenti-modal--documentazione): quando l'utente deve compiere un'azione consapevole per proseguire.

### Icona

Usa l’attributo `icon-name` con il nome di un’icona Bootstrap Italia per aggiungere automaticamente un elemento `<it-icon>` nell’header del dimmer, senza inserire markup aggiuntivo.



## Accessibilità

Il componente Dimmer è progettato per essere accessibile, ma assicurati di:

- includere sempre una descrizione significativa nello slot `content` quando lo usi per comunicare un messaggio;
- aggiungere etichette chiare e comprensibili per eventuali pulsanti.


## Varianti

Il dimmer supporta due varianti cromatiche, configurabili tramite l’attributo `variant`. Il dimmer supporta una variante cromatica primaria, con sfondo del colore primario, attivabile tramite l'attributo `variant="primary"`, e una variante scura `variant="dark"`.

### Variante primaria

Per la versione con sfondo di colore primario, usa l'attributo `variant="primary"`. Questa è anche la variante predefinita se l’attributo non viene specificato.

## Proprietà, metodi ed eventi accessibili via JS

Il componente espone metodi ed eventi utili per eventuali interazioni via JavaScript.

### Metodi

Il componente espone i seguenti metodi pubblici per la gestione programmatica:

- `show()`, mostra il dimmer;
- `hide()`, nasconde il dimmer;
- `toggle()`, alterna lo stato di visibilità.

```js
const dimmerEl = document.getElementById('myDimmer');

dimmerEl.show();   // mostra
dimmerEl.hide();   // nasconde
dimmerEl.toggle(); // alterna
```

<Canvas of={Stories.AttivazioneViaJS} />

### Eventi

Il componente emette i seguenti eventi custom:

- `it-dimmer-show`, quando il dimmer diventa visibile;
- `it-dimmer-hide`, quando il dimmer viene nascosto.

```js
const dimmerEl = document.getElementById('myDimmer');

dimmerEl.addEventListener('it-dimmer-show', (e) => {
  console.log('Dimmer visibile', e.detail.dimmer);
});

dimmerEl.addEventListener('it-dimmer-hide', (e) => {
  console.log('Dimmer nascosto', e.detail.dimmer);
});
```

## Personalizzazione degli stili

Per personalizzare gli stili, usa i selettori `::part` dedicati:

- `::part(dimmable)`, per il wrapper che racchiude l'intero componente;
- `::part(dimmer)`, per l'elemento overlay;
- `::part(dimmer-inner)`, per il contenitore centrale del contenuto dell'overlay;
- `::part(dimmer-icon)`, peril wrapper dell'icona (presente solo se `icon-name` è valorizzato).

[Vai alla guida sul selettore part](/docs/personalizzazione-degli-stili--documentazione#selettore-part)
