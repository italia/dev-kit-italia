## Cosa fa

Il componente Back permette all’utente di tornare alla pagina precedente, risultando particolarmente utile nei processi a più step, come la compilazione di una richiesta di un servizio o di un questionario. Puoi implementarlo come link o pulsante.

[Approfondisci quando e come usare il componente Back](https://designers.italia.it/design-system/componenti/back/)

### Alternative a questo componente
- [Breadcrumbs](/docs/componenti-breadcrumbs--documentazione): per orientarsi nella navigazione di pagine con contenuti informativi.

## Anteprima e attributi del componente
Questo componente non possiede attributi, ma si basa su una struttura HTML predefinita e riutilizzabile. Per vedere l'anteprima del codice, clicca su **Show code**.

## Indicazioni generali

Avvolgi nel componente `<it-back>` un link o un pulsante con la classe `.go-back`. Il componente implementa di default la funzionalità "torna indietro" tramite `window.history.back()`, che replica il comportamento del pulsante "Indietro" nativo del browser navigando indietro di una singola entry nello stack della cronologia.

`window.history.back()` è il comportamento predefinito adatto alla navigazione standard del browser. Se usi framework moderni con un proprio sistema di routing (React/NextJS, Remix, TanStack, Angular, Svelte, Vue.js, ecc.), puoi **sovrascrivere il comportamento** intercettando l'evento `it-back-navigate`:

```javascript
const back = document.querySelector('it-back');
back.addEventListener('it-back-navigate', (e) => {
  e.preventDefault(); // impedisce window.history.back()
  // ...naviga indietro secondo le indicazioni del tuo framework...
});
```

## Accessibilità

Quando necessario, includi un testo alternativo per i lettori di schermo usando un tag `<span>` con classe `.visually-hidden`.

## Link

Se vuoi implementare il componente come un link, aggiungi la classe `.go-back` al tag `<a>` e avvolgilo in `<it-back>`.

Per rendere il componente accessibile e navigabile da tastiera, specifica un valore per l'attributo `href`.

## Pulsante


Se vuoi implementare il componente come un pulsante, applica la classe `.go-back` al componente `<it-button>` e avvolgilo in `<it-back>`.
