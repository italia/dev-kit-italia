# Icon

<description>Componente per l'utilizzo di icone del design system e icone personalizzate.</description>

## Cosa fa

Il componente Icon (`<it-icon>`) permette di visualizzare le icone SVG disponibili nel Design system Italia, utilizzare icone SVG personalizzate o caricare icone SVG tramite URL.

Tutte le icone vengono caricate unicamente in modalità asincrona.

[Approfondisci come e quando usare icone](https://designers.italia.it/design-system/fondamenti/icone/)

## Accessibilità

Per impostazione predefinita, le icone sono considerate decorative. Il componente aggiunge automaticamente gli attributi `role="presentation"` e `aria-hidden="true"` all'elemento SVG, in modo che le tecnologie assistive le ignorino.

Se invece valorizzi l'attributo `label`, il componente inserisce un elemento `<title>` all'interno dell'SVG, lo collega tramite `aria-labelledby` e imposta `role="img"`. In questo modo, i lettori di schermo possono leggere la descrizione dell'icona.

## Varianti di colore

Usa l'attributo `color` per cambiare il colore dell'icona.

## Varianti di dimensione

Il componente `<it-icon>` ha 4 dimensioni predefinite: `xs`, `sm`, `lg`, `xl`. Usa l'attributo `size` per impostare la dimensione desiderata.

<Canvas of={Stories.VariantiDimensione} />

## Varianti di allineamento

Per cambiare l'allineamento dell'icona all'interno di un elemento, usa l'attributo `align` con i valori `top`, `middle` o `bottom`.

<Canvas of={Stories.VariantiAllineamento} />

## Spaziatura

Per creare attorno all'icona un padding proporzionale alla dimensione dell'icona stessa, applica l'attributo `padded` al `<it-icon>`.

## Icone disponibili

Tutte le icone SVG disponibili nel Design system Italia. Puoi cercare un'icona per nome e cliccarla per copiarne il nome identificativo da usare nell'attributo `name`.

## SVG personalizzato

Per usare `<it-icon>` come contenitore per un SVG personalizzato, inseriscilo nello slot:

```html
<it-icon size='sm' label='Icona utente'>
  <svg viewBox="0 0 24 24">
    <circle cx="12" cy="12" r="10" fill="red"></circle>
  </svg>
</it-icon>
```

In questo modo il componente:
- gestisce l'accessibilità;
- rimuove eventuali `<title>` duplicati;
- forza `aria-hidden="true"`, se necessario.

<Canvas of={Stories.SVGPersonalizzato} />

## SVG esterno

Per usare un'immagine esterna come icona, inserisci l'URL dell'SVG nell'attributo `src` del componente.

```html
<it-icon src="https://…/logo.svg" label="Logo"></it-icon>
```
