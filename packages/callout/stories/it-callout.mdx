# Callout

<Description>
  Box con uno stile visivo distintivo per evidenziare contenuti testuali importanti su pagine lunghe
</Description>

## Cosa fa

I callout possono essere utilizzati per evidenziare alcune parti del testo che richiedono particolare attenzione.
Possono contenere messaggi di errore, avvertimento, suggerimenti, ecc.

[Approfondisci quando e come usare il componente Callout](https://designers.italia.it/design-system/componenti/callout/).

Il componente può essere utilizzato con diverse configurazioni:

- **Titolo e contenuto**: inserendo un elemento nello slot `title` per il titolo e il contenuto principale nello slot di default
- **Con icona**: aggiungendo un'icona nello slot `icon` che verrà automaticamente colorata in base alla variante
- **Varianti di colore**: utilizzando l'attributo `variant` per applicare stili diversi (primary, success, warning, danger)
- **Modalità highlight**: con l'attributo `highlight` per ottenere un bordo solo sul lato sinistro
- **Modalità approfondimento**: con l'attributo `more` per contenuti estesi

## Accessibilità

Nel caso l'icona comunicasse visivamente contenuti non disponibili nel testo (ad esempio un allarme o una
conferma) questa andrà affiancata da un testo riservato agli screen reader.

## Callout base

Il callout base è costituito da un web component `<it-callout>` che genera la struttura HTML necessaria in base alla variante: inserisci il contenuto in un tag `<p>` al suo interno.

È possibile aggiungere un titolo utilizzando lo slot `title` e il contenuto principale utilizzando lo slot di default.

Al titolo può essere aggiunta un'icona utilizzando lo slot `icon`. L'icona viene automaticamente colorata in base alla proprietà `variant` del callout, eliminando la necessità di specificare manualmente l'attributo \`color\`.

## Varianti di colore

### Callout primario

Utilizza la variante primary per applicare il colore primario agli elementi grafici del callout. È consigliato per dare un evidenza particolare al componente nel contesto della pagina.

<Canvas of={CalloutStories.CalloutPrimario} />

### Callout success

Utilizza la variante success per indicare una procedura andata a buon fine.

<Canvas of={CalloutStories.CalloutSuccess} />

### Callout warning

Utilizza la variante warning per indicare una procedura o testo che richiede l’attenzione dell’utente.
