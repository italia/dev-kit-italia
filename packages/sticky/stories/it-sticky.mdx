# Sticky

<description>Comportamento che rende un elemento costantemente visibile allo scorrere della pagina.</description>

## Cosa fa

Il componente Sticky (`it-sticky`) mantiene un elemento visibile mentre l'utente scorre la pagina. Questo è particolarmente utile per menu di navigazione, call-to-action importanti, pulsanti di contatto o supporto che devono sempre rimanere accessibili.

[Approfondisci quando e come usare il componente Sticky](https://designers.italia.it/design-system/componenti/sticky/)

## Indicazioni generali

Il componente `<it-sticky>` consente di mantenere visibile un elemento della pagina durante lo scroll, applicando automaticamente il comportamento "sticky".

Per applicare il comportamento sticky a un elemento o contenuto, racchiudilo all'interno del tag `<it-sticky>`.
Il componente gestisce in autonomia anche casi avanzati, come elementi impilabili o con padding e classi personalizzate, attraverso specifiche proprietà.

Consulta [questa pagina di esempio](?path=/story/esempi-sticky--single-sticky) per comprenderne appieno il comportamento di un componente sticky.

## Accessibilità
Per garantire un'esperienza accessibile:

- non usare troppi componenti sticky sulla stessa pagina contemporaneamente;
- assicurati che il contenuto all'interno del componente sia chiaro, facilmente comprensibile e interagibile.

## Position fixed

Il componente assegna di default all'elemento da fissare la proprietà CSS `position` con valore `sticky`. In alcuni casi, questo può causare problemi di posizionamento, soprattutto se l'elemento cambia altezza quando diventa sticky. 

Puoi modificare la posizione dell'elemento, usa l'attributo `position-type:"fixed"`. 

[Vai all'esempio per questa funzionalità](?path=/story/esempi-sticky--fixed-sticky)

## Classi personalizzate

Per personalizzare lo stile dell'elemento quando è sticky o fixed, usa la proprietà `sticky-class-name`. Tutte le classi CSS che inserisci in questo attributo verranno aggiunte all'elemento quando diventa sticky e rimosse quando torna normale.

## Proprietà, metodi ed eventi accessibili via js

### Eventi

Il componente `it-sticky` emette questi eventi custom:

- **it-sticky-on**, quando l'elemento diventa sticky;
- **it-sticky-off**, quando l'elemento smette di essere sticky.

Entrambi gli eventi hanno le seguenti proprietà:

- `bubbles: true`, l'evento si propaga attraverso il DOM;
- `composed: true`, l'evento attraversa i confini del Shadow DOM;
- `cancelable: true`, l'evento può essere cancellato;
- `detail: { id: string }`, contiene l'ID dell'elemento sticky.

#### Esempio di utilizzo

```javascript
const stickyElement = document.querySelector('it-sticky');

// Ascolta quando diventa sticky
stickyElement.addEventListener('it-sticky-on', (event) => {
  console.log('Elemento diventato sticky:', event.detail.id);
  // Aggiungi logica personalizzata
});

// Ascolta quando smette di essere sticky
stickyElement.addEventListener('it-sticky-off', (event) => {
  console.log('Elemento non più sticky:', event.detail.id);
  // Aggiungi logica personalizzata
});
```
